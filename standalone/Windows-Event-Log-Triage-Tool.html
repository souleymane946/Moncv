Apprendre a enqueter sur des evenements de securite Windows

Exportez des evenements depuis l'Observateur d'evenements Windows, chargez le CSV ici, et obtenez un rapport de triage de type SOC : quels evenements meritent une investigation, comment ils se correlent entre eux, et pourquoi.

Avertissement important

  • Outil educatif de triage SOC. Les constats indiquent une activite qui merite une investigation et ne prouvent pas un comportement malveillant.
  • Analysez uniquement des journaux provenant de systemes que vous possedez ou que vous etes autorise a investiguer.
  • Un evenement de securite isole raconte rarement toute l'histoire : c'est la correlation qui construit le contexte.

      5. Exemples de demonstration

      Journaux entierement fictifs : comptes, noms de machines et adresses IP inventes, dans des plages privees. Aucune personne ni organisation reelle.

      6. Comment penser comme un analyste SOC

      1. Identifier l'evenement. Quel Event ID, quelle source, a quel moment ?
      2. Comprendre ce qui s'est produit. Que signifie cet identifiant en clair ?
      3. Identifier l'utilisateur ou le systeme concerne. Qui est touche ?
      4. Determiner si l'activite est attendue. Une maintenance planifiee, un deploiement, un administrateur connu ?
      5. Rechercher des evenements lies. Un evenement isole est faible ; une sequence est parlante.
      6. Correler authentification et privileges. Echecs suivis d'une reussite ? Compte cree puis ajoute a un groupe privilegie ?
      7. Recueillir davantage d'evidence. Journaux Sysmon, EDR, MFA, tickets de changement.
      8. Decider si une escalade est necessaire. Trier, c'est prioriser.

      Message cle : « Un evenement de securite isole raconte rarement toute l'histoire. Les analystes construisent le contexte en correlant plusieurs evenements. »

      Et : « Une detection est une raison d'enqueter, pas une preuve qu'un attaquant est present. »

      7. Comment exporter vos journaux Windows

      1. Ouvrez l'Observateur d'evenements (touche Windows, tapez eventvwr).
      2. Developpez Journaux Windows puis cliquez sur Securite.
      3. Filtrez si besoin (par exemple Filtrer le journal actuel → Event ID 4624, 4625, 4720...).
      4. Selectionnez les evenements souhaites (Ctrl+A pour tout prendre).
      5. Clic droit → Enregistrer les evenements selectionnes sous... et choisissez le format CSV.
      6. Chargez ce fichier CSV dans cet outil.

      Note importante : l'Observateur d'evenements n'exporte pas toujours directement en CSV selon les versions de Windows. Si le format CSV n'est pas propose, vous pouvez : exporter en .txt (accepte par cet outil s'il est tabule ou separe par des virgules), ou utiliser PowerShell en local pour produire un CSV, par exemple :

      Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4624,4625,4720,4726,4728,4732,1102,4688,7045} -MaxEvents 500 |
  Select-Object LevelDisplayName, TimeCreated, ProviderName, Id, Task, UserId, MachineName, Message |
  Export-Csv -Path "$env:USERPROFILE\Desktop\evenements-securite.csv" -NoTypeInformation -Encoding UTF8

      Cette commande s'execute localement sur votre machine. Elle peut necessiter un terminal lance en tant qu'administrateur pour lire le journal Securite.
